# FreePour MVP roadmap

These notes are mirrored into GitHub issues after the initial repository is published.

1. **Bootstrap and deployment hardening** — automatic migrations, seed flow, health checks, Unraid template, backup/restore notes, reverse-proxy/TLS guidance.
2. **Authentication and venue onboarding** — invite/reset flows, secure refresh sessions, venue creation wizard, screen pairing codes, rate limiting and audit log.
3. **Realtime game runtime** — authoritative server state machine, reconnect/resume, lobby/countdown/results phases, moderation and load testing.
4. **Ship five starter games** — implement Quick Draw, Perfect Pour, Higher or Lower, Trivia question management, and deterministic Plinko physics.
5. **Campaigns and ad scheduling** — creative upload, targeting, weighted rotation, impression reporting and content safety controls.
6. **Prize fulfillment (feature flagged)** — eligibility/rules engine, inventory, claim codes, venue redemption UI and compliance checklist; remain disabled by default.
7. **Venue operations** — kiosk recovery, heartbeat dashboard, offline signage, remote refresh, observability and alerts.
8. **Pilot readiness** — accessibility, privacy/terms, retention policy, analytics, QA matrix and first-venue runbook.
